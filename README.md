## Featured Project

### ✈️ AeroImpact — Disruption Intelligence for Complex Operations

A simulation and decision-support system for studying how flight delays propagate through airport gate schedules.

**What it currently does**

-   Simulates flight disruptions and schedule conflicts
    
-   Calculates a heuristic operational impact score
    
-   Evaluates alternative gate assignments
    
-   Checks aircraft compatibility and downstream conflicts
    
-   Generates synthetic disruption scenarios
    
-   Trains a Random Forest model to estimate simulated disruption impact
    
-   Runs through an interactive Streamlit dashboard
    
-   Includes automated tests for the core logic
    

**Stack**

`Python`  `scikit-learn`  `pandas`  `Streamlit`  `Plotly`  `pytest`

[View AeroImpact →](https://github.com/SuprisBasnet/aeroimpact)
